# Excel Analysis

This folder represents the Excel analysis phase of the UCI Online Retail project.

The original Excel workbook contains the initial data inspection, quality assessment, investigations, and analysis carried out during the challenge.

**Note:** The workbook is not included in this repository because its file size is approximately 40 MB, exceeding GitHub's browser upload limit.

The analysis was continued in Python to handle the large dataset more efficiently.

The Excel workbook is retained locally.

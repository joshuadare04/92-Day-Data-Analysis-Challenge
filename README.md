# 92-Day Data Analysis Challenge

A 92-day journey of practical data analysis projects covering Advanced Excel, Power BI, and SQL.

## About the Challenge

I started this challenge on October 1, 2026, with one goal: to strengthen my data analysis skills through consistent, hands-on practice.

Rather than focusing only on tutorials, I'm working with real datasets, solving analytical problems, documenting my process, and sharing what I learn along the way.

This challenge is about building practical skills, improving problem-solving abilities, and becoming more confident in turning raw data into meaningful insights.

### November — Power BI Analysis

| Week | Project | Status |
|---|---|---|
| Week 5 | UCI Online Retail – Interactive Power BI Dashboard | Completed |

**Week 5 Project: UCI Online Retail Dashboard**

Building on the data preparation completed in October, I continued working with the UCI Online Retail dataset to develop an interactive five-page Power BI dashboard.

The dashboard explores five major areas:

1. Sales Overview
2. Sales Trends & Performance
3. Product Performance Analysis
4. Customer Analysis & Insights
5. Geographic Sales Analysis

**Key Highlights**

- Developed DAX measures for business performance indicators.
- Created interactive KPI cards and visualisations.
- Analysed revenue, orders, customers, products, and geographic performance.
- Implemented synchronised slicers and cross-page filtering.
- Designed a reset filters feature for improved user experience.
- Documented the dashboard development process and final project.

The project provided practical experience in Power BI, DAX, business intelligence, and interactive dashboard development.

# 92-Day Data Analysis Challenge

A 92-day journey of practical data analysis projects covering **Advanced Excel, Power BI, and SQL**.

## About the Challenge

I started this 92-Day Data Analysis Challenge on **October 1, 2026**, with the goal of improving my data analysis skills through consistent, practical project work.

Rather than focusing only on tutorials, the challenge is centered around working with real datasets, solving business problems, documenting the process, building projects, and sharing what I learn along the way.

The challenge runs across three months:

* **October — Advanced Excel**
* **November — Power BI**
* **December — SQL**

Each week focuses on a dataset or project, with the work documented and organized into a growing portfolio.

## Week 1 — Maven Coffee Shop Sales Analysis

My first project focuses on the **Maven Coffee Shop Sales** dataset and was completed using Microsoft Excel.

The project covered:

* Data preparation
* Business analysis
* Product analysis
* Pricing and performance analysis
* Time analysis
* Dashboard development
* Final insights and recommendations

### Key Results

* **Total Sales:** $698,812.33
* **Total Transactions:** 149,116
* **Total Quantity Sold:** 214,470
* **Average Transaction Value:** $4.69
* **Product Types:** 29
* **Store Locations:** 3

The project also identified important patterns around category performance, product revenue versus volume, store performance, monthly growth, and peak sales periods.

**Week 1:** Completed

## Documentation Approach

A major part of this challenge is documenting the learning process.

Each project is broken down into daily or milestone-based documentation covering:

1. What was done
2. How it was done
3. What was discovered
4. What was learned
5. What the results mean from a business perspective

This allows the repository to show not only the final result, but also the process behind it.

# UCI Online Retail – Power BI Dashboard

## Project Overview

This project focuses on transforming the UCI Online Retail dataset into an interactive business intelligence dashboard using Microsoft Power BI.

It is part of my 92-Day Data Analysis Challenge, where I apply practical data analytics tools and techniques to real-world datasets.

The project builds on the data preparation and exploratory analysis completed in Week 4, taking the analysis further through interactive visualisation, business intelligence and performance reporting.

The goal is to explore the retailer's sales performance, product performance, customer behaviour and geographic distribution, while presenting useful business insights through an interactive dashboard.

## Project Objectives

- Develop an interactive Power BI dashboard.
- Analyse overall sales and revenue performance.
- Identify top-performing products and countries.
- Examine customer purchasing behaviour.
- Understand sales trends over time.
- Explore geographic revenue distribution.
- Apply DAX measures for business performance analysis.
- Build a professional, interactive and user-friendly reporting experience.

## Dataset

**Dataset:** UCI Online Retail Dataset

**Source:** UCI Machine Learning Repository

The dataset contains transactions from a UK-based online retail business between 1 December 2010 and 9 December 2011.

Original dataset:
- 541,909 records.
- 8 original columns.
- 38 countries represented.

The data preparation, cleaning, quality investigation and feature engineering were completed during Week 4.

## Tools and Technologies

- Microsoft Power BI – Data modelling, DAX and dashboard development.
- Python – Data preparation and transformation completed in the preceding project phase.
- Pandas – Data manipulation and preparation.
- Microsoft Excel – Initial data exploration and validation.
- GitHub – Project version control and portfolio documentation.

## Dashboard Structure

The report contains five interactive pages.

### 1. Sales Overview
Provides a high-level summary of business performance.

Key metrics:
- Total Revenue
- Total Orders
- Total Customers
- Total Quantity Sold
- Average Order Value
- Cancellation Rate

Visualisations:
- Monthly Revenue Trend
- Top 10 Countries by Revenue
- Top 10 Products by Revenue

### 2. Sales Trends & Performance
Explores changes in sales performance over time and highlights important revenue and order trends.

### 3. Product Performance Analysis
Examines product-level performance, identifying products contributing significantly to overall revenue and sales activity.

### 4. Customer Analysis & Insights
Explores customer purchasing patterns and provides insights into customer activity and contribution to sales.

### 5. Geographic Sales Analysis
Examines the geographical distribution of the retailer's sales.

Visualisations:
- Total Countries Served
- Top 10 Countries by Order Volume
- Top 10 Countries by Revenue
- Top 5 Countries by Revenue Contribution

## Key Performance Indicators

The completed dashboard displays the following headline metrics:

| Metric | Result |
|---|---:|
| Total Revenue | £10.66M |
| Total Orders | Approximately 21K |
| Total Customers | Approximately 4K |
| Total Quantity Sold | Approximately 6M |
| Average Order Value | £514.14 |
| Cancellation Rate | 18.51% |
| Countries Served | 38 |

Revenue calculations exclude cancellation transactions, zero-price negative adjustments, bad-debt adjustments and negative unit-price records.

The dataset does not contain product cost information, so profit and profit-margin calculations are outside the scope of this project.

## Interactivity and User Experience

The dashboard includes:
- Country slicer.
- Product slicer.
- Month and year date filtering.
- Synchronized slicers across report pages.
- Cross-filtering between visuals.
- Reset All Filters functionality.

These features allow users to explore the data from different perspectives without navigating away from the report.
